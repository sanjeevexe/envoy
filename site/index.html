envoy
1 The idea

Muse has a computer. Envoy gives it a phone.

Envoy gives an AI agent its own Android phone, so it can use what only exists in apps: a song from Instagram's library on a Reel, a poll on a Story, a TikTok sound. Anything an agent asks for that can't be undone waits for your yes on your iPhone. And a run Envoy has verified can be compiled into a checked routine it replays with few or no model calls, which you can give every agent as a new tool.

Muse is Meta's assistant, on the Mac and in its iPhone app. Any agent that speaks MCP calls Envoy the same way.
