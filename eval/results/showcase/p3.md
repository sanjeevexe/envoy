`eval/run_showcase.py gate` fires on Instagram's two screens and TikTok's post screen (that dump is kept outside the
repo: the screen suggests nearby places, which give away where the phone is) ("irreversible by rule, and a
post's request doesn't approve it"). It does **not** match on TikTok's editor because of "Your Story".

The feed's own "Your story" bubble (id `outer_container`, in the reels tray at the top of Home) is a different element
and is not caught by id. That's right: it only opens the camera.

## Leaving without posting
- The Reel: Back to the editor, Cancel, "Start over" (`scripts/instagram_take.py` `leave_composer`).
- The Story: Cancel, then "Discard edits?" › Discard. `leave_composer` loops between the Story camera and its gallery;
  "Back to Home" twice ends it.
- Opening Create offered a half-made reel from an earlier run ("Keep editing your draft?"). I answered "Start new
  video", as the take setup does, which keeps it as a private draft.

## Recommendation (the user picks)

No camera, no microphone, and every step but one reachable by label:

| Post | Feature | Why it's the pick |
| --- | --- | --- |
| Instagram | **A Reel with a song from the library** (or a Story with a poll; both work) | Muse's Instagram connector can't put licensed music on a reel; the song search and pick are plain labelled taps |
| TikTok | **A library sound**, optionally plus an effect | No connector for TikTok; the effect is labelled. The search result needs one point tap |
| YouTube Shorts | **A library sound** | No connector; labelled search. Needs the channel first |

Using the **same song on all three** reads well on screen: JVKE's "golden hour" is in TikTok's and YouTube's
libraries (checked); Instagram's wasn't searched for it (I tried "What a Wonderful World").

Not recommended: TikTok Duet, TikTok voiceover and YouTube green screen. Each records with the Pixel's camera or
microphone, which films or hears the room, and Duet sits next to a stranger's video.

## Before any agent run (the coordinator's rule change, and the user)
1. **TikTok's editor "Your Story" (`ts6`) isn't caught by rule**, and every TikTok flow passes through that screen.
   One wrong tap posts a Story. Until the rule catches it, an agent run on TikTok has only the model's label in the
   way, so treat TikTok like YouTube: no agent run until the change lands. "Repost" in TikTok's share sheet is the
   same kind of gap, though no showcase path reaches it.
2. **YouTube:** the user creates the test account's channel (YouTube › You › Create channel; it suggested the name
   "envoy"). Then I record the upload button (≈10 minutes on the Pixel).
3. **Permissions are done:** TikTok has camera, microphone, and photos and videos; YouTube has camera and microphone,
   and its gallery opened without asking.
