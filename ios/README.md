# ios

Not built. The iPhone companion is Envoy's web app added to the Home Screen (approvals by web push, the live view,
voice, photos), so no native app or Apple Developer account was needed. The iPhone's other pieces are Apple Shortcuts:
"Send to Envoy" from the share sheet, the sign-in code forwarder, and "Ask Envoy" for Siri, the Action Button and
Control Center (`scripts/make_shortcut.py`, `docs/siri.md`).
